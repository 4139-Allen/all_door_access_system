## 每课核心收获

### 第 1 课：环境搭建 + 第一个接口测试 ✅
- 装 `pytest` + `requests`
- 发 HTTP 请求、解析 JSON 响应
- `assert` 断言
- 确认后端接口地址：`http://127.0.0.1:8000/api/...`

### 第 2 课：Fixture 入门 ✅
- `@pytest.fixture` 声明夹具
- `yield` 实现 setup/teardown
- fixture 通过函数参数自动注入

### 第 3 课：Scope + fixture 组合 ✅
- scope 级别：`function` / `class` / `module` / `session`
- fixture 可以依赖其他 fixture（`admin_client(client)`）
- session 级 fixture 只执行一次，提升效率

### 第 4 课：conftest.py ✅
- conftest.py 的 fixture 自动对同目录下所有测试文件可见
- 不需要 import
- 可以多层 conftest.py，内层覆盖外层

### 第 5 课：参数化 ✅
- `@pytest.mark.parametrize("变量", [数据])`
- `ids` 让用例名可读
- 每组数据跑一次测试

### 第 6 课：数据与代码分离 ✅
- JSON/YAML 文件管理测试数据
- `load_cases()` 通用加载函数
- 加数据 = 加用例，不改代码

### 第 7 课：断言封装 ⬜
- `assert_success(resp)` ✅ 自动校验 code==200
- `assert_failure(resp, 400)` ✅ 校验错误码
- `AssertHelper` 链式调用 `.has_field("token").field_equals("role", "admin")`

### 第 8 课：日志系统 ⬜
- 测试失败自动打印请求 URL、请求体、响应体
- logging 配置
- pytest 的 `--log-cli-level=DEBUG`

### 第 9 课：钩子（hook） ⬜
- `pytest_runtest_makereport` — 测试结果回调
- `pytest_addoption` — 自定义命令行参数
- `pytest_configure` — 注册自定义标记

### 第 10 课：测试数据清理 ⬜
- 创建测试数据 → 测试 → 删除测试数据
- destructive 标记隔离危险用例
- 事务回滚法：每个测试在一个事务中运行，测试完回滚

### 第 11~20 课 ⬜
后续逐步补充

## 必须掌握的 pytest 命令

```bash
pytest                          # 运行所有
pytest -v                       # 详细输出
pytest -s                       # 显示 print
pytest -k "login"               # 按名称筛选
pytest -m smoke                 # 按标记筛选
pytest --co                     # 显示帮助
pytest --tb=short               # 短回溯
pytest --tb=long                # 长回溯
pytest --lf                     # 只跑上次失败的
pytest --ff                     # 先跑上次失败的，再跑其他的
```
